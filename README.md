# HASSAN SYSTEM — Android Edition v2.0

A native Android shell around the complete offline HASSAN SYSTEM web app.

## Build
1. Open this folder in Android Studio.
2. Let Gradle sync.
3. Run on a physical Android phone or emulator.
4. Build > Build APK(s) to create the APK.

The app includes a native notification/vibration bridge, portrait layout, persistent WebView storage, and the complete System UI.

Package: `com.hassan.system`
Version: `2.0`
